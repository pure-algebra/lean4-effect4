# Contract: the property loop (P-T6)

Light ceremony by operator ruling D2. The dispatch form (P-T9a) is checked on
generated flows, not only on the four hand-written goldens.

## Frozen behaviour (`harness/trace/Property.lean`, `scripts/check-lowering-property.sh`)

- Flows are generated by construction over the Cell family's type graph: a
  chain of blocks whose scope grows by one parameter per `perform`; every
  operation is picked among those whose request type is in scope; a `choose`
  may send its left arm back to an earlier block of matching arity. Every
  generated flow is admitted by `Effects.admit`, which is the free oracle: a
  refusal fails the gate as a generator bug.
- Tapes are built by policy through the runner itself, so every entry names
  the site the run reaches: `left`, `right`, `alternate`, `random`, one
  `only<site>` tape per site, and one `visit<site>` tape per loop site. Sites
  come in pairs (a forward split whose left arm enters a loop block, then the
  loop site itself: back to the split, or to itself with two same-typed
  parameters swapped), so both arms of every site are distinguishable on the
  trace. A tape longer than the cap (12) ends at the
  unanswered frontier; the host maps a tape exhausted at a `choose` to the
  same `frontier` row (`tracer.ts`).
- Per-site branch coverage: the gate fails if any site never took both
  branches across the corpus.
- All flows are lowered into one dispatch-form module and run once on the
  host (`effect4-batch`, effect4-tools); every case must agree with its
  Flow-runner golden under every mask.
- On a divergence the first failing case is shrunk against the host with a
  budget of 64 candidates (shorter tapes, a `choose` replaced by the branch
  taken, a type-neutral `perform` deleted) and stored as first-order data
  under `generated/lowering-property-failures/<program>.<tape>/`.
- `generated/lowering-property.tsv` records the seed, counts, and the corpus
  digest; the corpus is regenerated from the seed and never committed.
- `scripts/test-lowering-mutations.sh` plants three lowering mutants (swapped
  arms at a site, an ignored tape, an off-by-one tape cursor); each must
  diverge.
