# TypeScript target attacks

## E4-TARGET-CE-001 — producer-side string escaping

- **BROKE:** emitters can pre-escape values and the printer may concatenate
  them inside quotes.
- **WITNESS:** one value containing the selected quote, backslash, newline,
  carriage return, tab, and a Unicode character.
- **CLASS:** byte-generation ambiguity.
- **FIXED-BY:** `Render.escapeString` owns escaping and the retained reduction
  checks the exact result.

## E4-TARGET-CE-002 — width-adaptive layout

- **BROKE:** a formatter width or source-line length may decide object layout.
- **WITNESS:** a long ordinary object remains inline while the same field in
  `objectML` is multiline.
- **CLASS:** nondeterministic generated bytes across tools or settings.
- **FIXED-BY:** layout is a constructor choice plus child-newline inspection;
  there is no width input.

## E4-TARGET-CE-003 — raw declaration promoted to checked syntax

- **BROKE:** every `Decl` value is in the image of typed Effect4 lowering.
- **WITNESS:** `Decl.raw "arbitrary host text"` bypasses the closed expression
  and statement constructors.
- **CLASS:** target-profile escape hatch.
- **FIXED-BY:** retained only as a compatibility arm; the later lowering image
  must exclude it or replace it with an admitted structured helper form.

## E4-TARGET-CE-004 — quoted `__proto__` treated as ordinary object data

- **BROKE:** quoting an object-literal key is sufficient to preserve every JSON
  object entry.
- **WITNESS:** a raw JSON object with the own key `__proto__`; JavaScript
  object-literal semantics treat that spelling specially even when quoted.
- **CLASS:** target semantic mismatch.
- **FIXED-BY:** the JSON lowerer uses `Object.fromEntries` for this spelling,
  and generation rejects duplicate object keys before either representation
  can collapse them.

## Claim limit

The first two witnesses establish exact local printer behavior. They do not
establish TypeScript grammar validity, typing, Effect v4 compatibility, or
source-target simulation. The third attack deliberately keeps those graph
edges open. The fourth is also exercised by the direct TypeScript, Effect, and
language-service harness, but does not close general source-target simulation.
