A design language for Effect4 runs

Six studies drawn from corpus runs, each a rendering of the same notation. The written reference is design-language.md (§2 assigns the visual variables, §3 the glyphs, §4 decides time and causality); the string-diagram fold-in is string-diagrams-notes.md. The studies are not a viewer: they are the grammar a viewer would have to speak.

Reading axis
the trace index, equal steps. Never time; nothing here is a duration.
Hue is for agents
machine ink   host amber   failure madder   resource verdigris — four, no more.
Value is for state order
running > parked > not-yet; played > variation.
Numerals are for identity
fibers, tokens, keys, indices, paths, digests — read, never matched by colour.
Causality
drawn only as recorded relations: fork, task ran → entered, exit → observer → resume.
Scopes
enclosures [k … k] that must close; an unmatched bracket is an owed close.

a1 — pTwo as a score

a2 — pAcquireClosed: the enclosure that closed first

a3 — the same grammar in a terminal

b — the program, the Point, the stack

c — the tape, and a variation

d — three identities

What the studies could not draw solid

  • the yield's own scheduling (only its ranTask is recorded; a1 draws a dotted hollow ▹);
  • scope open and close and the closing exit (store operations; a2's enclosure is reconstructed from the program and the stores);
  • the row a park awaits (INV-TAPE-2 owes it; a3's frontier names it by hand);
  • the Point at any event, the frames as events, and the tape itself in the corpus manifest.

Each is a log row the language needs; design-language.md §6.4 lists them, and the engine's query layer marks them owed rather than guessing.

Sources

The full reading list, with the repository files and line ranges the language was read off and every primary source with its URL, is design-language.md §8, together with what was read and rejected and why. The primary sources the studies rest on:

  • Bertin, Sémiologie graphique — the visual variables and their levels (selective, associative, ordered, quantitative): why hue is for agents only and position for the index.
  • Wilkinson, The Grammar of Graphics — cross, nest, blend: the score is index * (fiber / segment) + index * queue + index * clock.
  • Lamport 1978 and Allen 1983 — happened-before and the thirteen interval relations: causality drawn only as recorded relations; enclosures read as intervals.
  • Reichenbach 1947 — speech, event and reference time: the cursor is R, the reading axis is never E.
  • Pearl's do-operator and Prior–Belnap branching time — a variation is an action on the tape and a history through one moment.
  • Talmy, force dynamics — an interrupt as an Antagonist arriving; Zacks & Tversky 2001 on event structure.
  • Iverson, Notation as a Tool of Thought; Victor, Learnable Programming — one notation for the written, spoken and drawn form.
  • Music notation (rests, bar lines, voltas, the fermata), PGN's recursive annotation variations, punched tape, locking tables — the borrowed conventions, each with its reason in §8.
  • Rejected there, with reasons: MSC lifelines and UML sequence diagrams, proportional timelines, statecharts as the drawing, Petri nets as the drawing, a colour per fiber.
