# docs/design

Design documents that belong in the tree (the research trail under `docs/research/` is
untracked working memory; what is here is what a reader of `main` needs).

| file | what |
| --- | --- |
| `design-language.md` | the design language for Effect4 runs: the semantic inventory, the visual variables assigned (Bertin's levels; hue for agents only), the notation (sexp, spoken, glyph), time and causality decided, the physical artifacts (receipt, printed tape, printed score, registry page, locking table, terminal), the plan for a visual designer, and what was read and rejected |
| `string-diagrams-notes.md` | the string-diagram frame folded into the language: premonoidal/Freyd categories, the tape as the runtime wire, D-DEFORM, spiders, named discard, three wire grades |
| `design-language/` | the six studies drawn from corpus runs — `a1-score-pTwo.svg`, `a2-score-pAcquireClosed.svg`, `a3-terminal-pFork-pAwait.txt`, `b-program-point-stack.svg`, `c-tape-variation-pFork.svg`, `d-three-identities.svg` — and `index.html`, one self-contained page that shows all six inline with their reading rules (the SVG and text files beside it are the same studies as separate, diffable sources) |

The studies are SVG and plain text on purpose: they print, they diff, and they are the grammar
a viewer would have to speak, not a viewer.
