1 · A primitive is a prototype and one argument

An Effect value is an object created from a per-op prototype by makePrimitive C:428–469. The prototype carries the op identifier, an [evaluate] function, and up to three continuation slots. The instance carries only [args]. There is no separate AST interpreter: stepping a value means calling its own [evaluate](fiber), which returns the next primitive or the Yield sentinel C:375–391.

The same protocol is reused for values that are not obviously effects. An Exit is a primitive whose [args] is the value or cause C:472–516. A YieldableError is an Error subclass whose evaluate is exitFail(this) C:566–583. A Context.Key evaluates to a service lookup E:2059.

2 · The run loop

A fiber holds a current primitive, a stack of primitives, an interruptible flag, an op counter, and a pending-interrupt cause E:526–550. evaluate is the only entry E:599–628; it is called synchronously by runFork, by every dispatcher task, and by interruptUnsafe when the fiber is parked. Each call runs one runLoop, which steps primitives until one of them returns Yield.

3 · The continuation stack

Combinators do not call each other. flatMap pushes itself and returns its inner effect; the inner effect eventually produces a value, and producing a value means popping. Only three evaluators pop: Success and Sync ask for a contA, Failure asks for a contE C:513, E:933, C:539. The pop is getCont E:680–698.

There is one entry, interruptUnsafe(fiberId, annotations) E:574–595. It always records the cause. Whether anything happens now depends on two bits: the mask and whether the fiber is inside runLoop at this instant.

5 · Forking and structured concurrency

All forks go through forkUnsafe(parent, effect, immediate, daemon, uninterruptible) E:5264–5284. The child is a new FiberImpl over the parent's current context. What differs between the public variants is only whether the child is registered in the parent's children set and what, if anything, will interrupt it later.

6 · Scope

A scope is a small state machine holding finalizers keyed by object identity Sc:99–189, E:3915–3922. Close flips the state before running anything, runs finalizers in reverse insertion order, and merges every failure into one cause.

7 · Scheduler

The scheduler decides two things: when a running fiber must stop, and when a queued task runs S:32–36. Both are services in the fiber's context, so a test can replace them without touching the runtime S:78–81, S:269–298.

8 · Exit and Cause

An Exit is Success{value} or Failure{cause}, and it is itself a primitive X:118–156, C:472–516. A Cause is a flat array of reasons with no tree, no sequential-versus-parallel distinction, and equality by ordered reasons C:138–176.

10 · What a model must not get wrong

  1. Frames are primitives. A frame is selected by which of contA, contE, contAll it defines, and contAll runs on every frame passed during a pop, not only on the frame that answers E:689–696.
  2. Interrupts bypass error handlers. Once interrupted and interruptible, Failure skips every contE frame until a mask frame flips the flag or the stack empties C:540–542. catchCause never sees an interrupt unless it sits inside an uninterruptible region.
  3. Yield is overloaded. It means "finished" when _yielded is an Exit and "parked" when it is a thunk E:656–668.
  4. Only forkChild tracks children. forkIn, forkScoped, forkDetach, and the races all fork daemons E:5279, E:5310, E:5366, E:1520.
  5. Children are interrupted after the Exit exists. The pass runs in evaluate between runLoop returning and observers firing, and only if the middleware was ever installed E:613–617.
  6. Scope close is LIFO with the state flipped first. Parallel close is immediate daemon forks inheriting the closer's mask; all failures merge into one flat cause E:3779–3827.
  7. Cause has no structure. causeCombine is a set-union of reasons; there is no sequential or parallel node E:242–258.
  8. Start is asymmetric. The root fiber runs synchronously on the caller's stack; children default to a deferred start on the parent's dispatcher at priority 0 E:5422, E:5277.
  9. Recording and applying an interrupt are separate. The cause is always stored; it becomes the outcome at the first checkpoint where the fiber is interruptible E:585–595.
  10. Budget is per runLoop entry. At most one scheduler yield is injected per entry, and the counter resets each entry E:636, E:644–652.
