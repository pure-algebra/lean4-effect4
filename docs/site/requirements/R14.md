# Requirement R14: A sketch checks and explains its types

This page explains requirement R14 in Effect4. It covers what the requirement asks for sketches and typed holes, why type slicing matters, and how the property is checked.

## What the requirement asks {#what-it-asks}

Requirement R14 demands that incomplete programs check incrementally and explain typing decisions across all subtrees (`docs/core/system-map.md` §8, row 282):
- Conservative sketch extension: a sketch with typed holes admits program syntax as a conservative extension of standard typing (`holes_conservative`).
- Typed replacement: replacing a focus at an address with a fitting sub-program keeps typing under `NodeHasTy` (`NodeHasTy.replace`).
- Address table coverage: the address table lists typing environments and checker diagnostics for every node (`refusals_nil_iff`).
- Minimal type slices: every queried type fact possesses a minimal slice over monotone property views (`SliceView.lattice_minimal`).

An edit session updates the address table incrementally without rechecking unrelated subtrees.

## Why it matters {#why-it-matters}

Interactive development environments, code editors, and language servers require immediate feedback on partial programs during authoring.

If typing checks require fully finished programs, developers receive no guidance while constructing complex effectful pipelines.

Providing typed holes, incremental replacement, and located refusals across address tables enables responsive tooling, precise diagnostic reporting, and guided refactoring.

## How it is checked {#how-it-is-checked}

The requirement is checked by proving conservative sketch extension, typed replacement, address table agreement, and minimal lattice slicing:
- Conservative sketch admission is stated by `holes_conservative` in `src/Effect4/Laws/Program/Sketch.lean`.
- Focus replacement is stated by `NodeHasTy.replace` in `src/Effect4/Laws/Program/Typing/Replace.lean`.
- Address table diagnostic agreement is stated by `refusals_nil_iff` (`src/Effect4/Laws/Program/Typing/Table.lean`).
- Minimal type slicing is stated by `SliceView.lattice_minimal` in `src/Effect4/Laws/Slice/Lattice.lean`.
