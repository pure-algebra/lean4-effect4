# Requirement R11: Resource release and finalization

This page explains requirement R11 in Effect4. It covers what the requirement asks for resource release guarantees, why disciplined finalization matters, and how the property is checked.

## What the requirement asks {#what-it-asks}

Requirement R11 demands that allocated resources are released reliably across all exit paths (`docs/core/system-map.md` §8, DB-07):
- At-most-once release: each registered cleanup executes at most once per registration, counted by identity.
- Strict close order: finalizers execute in reverse registration order across closed scopes and structured regions.
- State-first cleanup: a scope sets its closed bit before running any finalizer, preventing duplicate or re-entrant execution.
- Frontier state retention: state produced before reaching a live frontier is kept intact for subsequent continuation.

A scope that finishes cleanly or encounters a failure must not leak registered resources.

## Why it matters {#why-it-matters}

Concurrent applications acquire external resources including file handles, database transactions, network sockets, and timer registrations.

If finalizers ran out of order or executed multiple times, systems would suffer from use-after-free defects or corrupted state.

Cleanup in the reverse order of acquisition releases a resource before the resources it depends on.

## How it is checked {#how-it-is-checked}

The requirement is checked by proving scope transition, close ordering, and finalizer execution theorems:
- Idempotent closing and reverse-order execution are stated by `close_twice` and `closeOrder_eq` (`src/Effect4/Machine/Scope.lean`).
- Re-entrant addition semantics on closed scopes is stated by `close_reentrant_add` in the same file.
- Single close execution bounds are stated by `runState_complete` and `runState_prefix` (`src/Effect4/Laws/Machine/ScopeMachine.lean`).
- Finalizer start bounding is stated by `starts_le_pushes` (`src/Effect4/Laws/Program/FinalizerRun.lean`).

The plan on this page gives each theorem's status and the goals it rests on.
