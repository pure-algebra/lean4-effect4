# Requirement R2: Conservative extension

This page explains requirement R2 in Effect4. It covers what conservative extension requires across eight obligations, why typing signature independence matters, and how the property is checked.

## What the requirement asks {#what-it-asks}

Requirement R2 requires that extending an application signature is conservative across eight named obligations (DB-01, `docs/core/system-map.md` §8):
- C1 syntax: extending a signature leaves existing program representations unchanged.
- C2 meaning: extending operations leaves existing program denotations unchanged.
- C3 checker: extending a signature admits exactly the same existing programs.
- C4 protocol typing: existing programs keep their protocol certificates.
- C5 world: extending allocated operations projects onto earlier world states.
- C6 local lawfulness: appending rows keeps signature validity intact.
- C7 representation: target representations remain compatible.
- C8 forms: higher-level form expansions remain stable under extension.

Extending a signature must never alter the typing, semantics, or admission of existing programs.

## Why it matters {#why-it-matters}

Software composition relies on stability under modular extension.

If adding a new library, operation row, or service changed how existing programs run, modular verification would collapse.

Conservative extension lets separate modules compose without changing what the earlier ones mean.

## How it is checked {#how-it-is-checked}

The requirement is checked by proving conservative extension theorems for syntax, checking, meaning, and sums:
- Checker extension and restriction are stated by `check_ext` and `check_restrict` in `src/Effect4/Laws/Program/Signature.lean`.
- Signature lawfulness under appending is stated by `lawful_append` in the same file.
- Denotational meaning under row extension is stated on `StraightRows` by `meaningUnder_append` (`src/Effect4/Laws/Program/DenoteRowsAppend.lean`).
- That a signature sum is a coproduct of free monads is stated by `sum_is_coproduct` (`src/Effect4/Laws/Effects/Sum.lean`).

The plan on this page gives each theorem's status and the goals it rests on.
