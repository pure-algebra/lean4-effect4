# Requirement R8: Runs and faces as named connections

This page explains requirement R8 in Effect4. It covers what the requirement asks for execution faces and profiles, why named connections matter, and how the property is checked.

## What the requirement asks {#what-it-asks}

Requirement R8 demands that every face and backend operates as a named connection bounded by explicit profile data (`docs/core/system-map.md` §8, decisions row 79):
- Profile bounds: inside its declared profile, a face's observation equals the reference observation up to an identity bijection.
- Located refusal: outside its profile, the face refuses execution, including intermediate values that exceed supported bounds.
- Profile as data: target capabilities and numerical ranges are defined as first-order profile data rather than ad-hoc heuristics.
- Invertible target syntax: printing and reading target code form partial isomorphisms on readable domains.

A face must never silently compute unvetted answers outside its certified profile.

## Why it matters {#why-it-matters}

Effect4 presents multiple faces: application interfaces, printed TypeScript modules, and native OCaml engines lowered through LCNF.

Different target runtimes enforce different scalar limits, memory layouts, and feature subsets.

An explicit profile makes each face state the boundary it supports, so a difference between platforms is a refusal and not a silent divergence.

## How it is checked {#how-it-is-checked}

The requirement is checked by proving face simulations and print-read isomorphisms over declared profiles:
- Invertible syntax round-tripping is stated by `read_print` and `read_exact` in `src/Effect4/Laws/Codegen/ReadPrint.lean`.
- Meaning agreement on the `Straight` fragment is stated by `run_eq_meaning` (`src/Effect4/Laws/Program/Agreement/Segment.lean`).
- Loop step agreement on the `Looped` fragment is stated by `loopAgreement_of_straight` (`src/Effect4/Laws/Program/LoopAgreement.lean`).
- Reference simulation at the empty row table is stated by `run_eq_ref` (`src/Effect4/Laws/Program/RuntimeR.lean`).

The plan on this page gives each theorem's status and the goals it rests on.
