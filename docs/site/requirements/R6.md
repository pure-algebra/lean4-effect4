# Requirement R6: The host boundary

This page explains requirement R6 in Effect4. It covers what the requirement asks for external host interactions, why keyed host boundaries matter, and how the property is checked.

## What the requirement asks {#what-it-asks}

Requirement R6 demands that host interactions satisfy formal specifications and keyed session contracts (`docs/core/system-map.md` §8, `docs/core/host-boundary.md`):
- Host specification: external interactions follow a specification `H : HostSpec` satisfying `LawfulHostSpec`.
- Receipt and application: host answers submit through preflight checks and apply at most once.
- Envelope matching: replies correlate to waiting calls by matching version, session, call identifier, key, and row.
- Handle protection: internal handle kinds like cells and scopes are prohibited from crossing host boundaries (decisions row 97).

External replies must satisfy typing admission before resuming waiting fibers.

## Why it matters {#why-it-matters}

Asynchronous software interacts with untrusted external environments such as web APIs, database drivers, and operating system calls.

If host completions bypassed verification, malformed data or duplicated callbacks could corrupt internal memory or trigger invalid transitions.

A defined host boundary lets a host's replies meet the machine's invariants without assuming that the host makes progress.

## How it is checked {#how-it-is-checked}

The requirement is checked by proving reply admission, call correlation, and session agreement theorems:
- Admitted success preparation is stated by `preflight_success_prepared_fits` (`src/Effect4/Laws/Api/HostSession.lean`).
- Defect-free failure admission is stated by `preflight_failure_noShapeDefect` in the same file.
- Call instance correlation is stated by `instance_prepared_success` (`src/Effect4/Laws/Program/Admit.lean`).
- Session agreement with reference replay is stated by `session_eq_ref` (`src/Effect4/Laws/Api/SessionRef.lean`).
- Host comodel meaning is stated by `denoteRows_eq_session_host` (`src/Effect4/Laws/Api/SessionMeaning.lean`).

The plan on this page gives each theorem's status and the goals it rests on.
