# Sources from the Web Standards Semantics reading map

All 21 papers and the Web IDL standard named on the attached reading-map page were downloaded on 2 September 2026. Every requested source is available below.

The collection contains 21 original PDFs (568 pages) and one complete HTML snapshot. Original documents retain their downloaded bytes. Each also has a searchable text copy; use the original for equations and layout.

Checks confirmed the file contents and sizes, matched each paper title, extracted every PDF page, and independently checked the PDF page counts. The Web IDL title and cited exceptions section are present. Choice Trees is the specifically requested arXiv version 1; the Framework paper is the 2023 version 1 preprint.
