  release runs to its end there too.
- So `closeA` cannot be Step 0's program: `make check-truth` would refuse it unsigned. The
  machine already gives 4.0.1's answer on it, so item 2 would not move it either.

## Appendix: `release_probe.py`

The probe ran from the session scratchpad, outside the repository. It reuses the release lane's
own work copy and runner (`scripts/check-truth-release.py`) on a manifest cut to the named
programs. Command: `python3 release_probe.py <repo> <manifest> <work dir>
/Users/pooks/Dev/lean4-effect4/ts/release/node_modules poisonNoHandler closeA closeE`.

```python
"""Run named programs of a manifest on effect@4.0.1 through the release lane's own work copy.

A probe, not a gate: it reuses `build_work_copy` and `host_run` of
`scripts/check-truth-release.py` and prints each named program's row.

    python3 release_probe.py <repo root> <manifest> <work dir> <release node_modules> <name>...
"""
import importlib.util
import json
import sys
from pathlib import Path

repo, manifest_path, work, modules = (Path(a) for a in sys.argv[1:5])
names = sys.argv[5:]
spec = importlib.util.spec_from_file_location('ctr', repo / 'scripts/check-truth-release.py')
ctr = importlib.util.module_from_spec(spec)
spec.loader.exec_module(ctr)
bun, _modules, host_path, driver = ctr.truth_host.select_release(
    repo, {'EFFECT4_RELEASE_NODE_MODULES': str(modules)})
manifest = json.loads(manifest_path.read_text())
manifest['programs'] = [p for p in manifest['programs'] if p['name'] in names]
ctr.build_work_copy(work, modules, ctr.truth_host.RELEASE_ENTRY_POINTS, driver)
result = ctr.host_run(bun, host_path, work, modules, (json.dumps(manifest, indent=2) + '\n').encode())
print('effect', result['effect'])
for row in result['rows']:
    host = row.get('host') or {}
    print(row['program'], '| lean', row['leanExit'], '| host', row['hostExit'],
          '| exit', row['exitAgree'], 'schedule', row['scheduleAgree'], 'sync', row['runSyncAgree'])
    print('  host schedule', [x for x in host.get('schedule', []) if not x.startswith('scheduled')])
    print('  notes', row['notes'])
```
