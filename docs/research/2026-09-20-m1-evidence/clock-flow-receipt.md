# Clock lowering receipt

The local clock lowering reads original Nat literals before ordinary OCaml integer lowering. The three checked routes are direct `ofNat`, numeral syntax, and `positive` after local aliases. Each emits its exact decimal through `E4_clock.literal`, including values above OCaml `max_int`.

A finite dependency pass reads helper calls and local aliases from mono LCNF. It computes which helper parameters can reach clock ingress, and refuses a saturated argument to those parameters. The pass reaches a fixed point using bounds derived from the finite dependency and parameter sets. The checked red routes are local arithmetic, a noinline wrapper, and a nested noinline wrapper. An unrelated Nat arithmetic control still translates under the existing saturation policy.
