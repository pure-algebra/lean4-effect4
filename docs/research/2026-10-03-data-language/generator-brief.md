# Generator bootstrap slice

Base: `82d34358`. Decision: row 194.

The early generator must build without importing an Effect4 library module.
It reads declarations through each manifest row's declared imports.
Catalogue generators build separately because they inspect compiled Effect4 values.
Generation refreshes an upstream output before building a consumer of that output.
The manifest remains the owner of arguments and output paths.

This slice changes build orchestration, not a semantic judgment.
It adds no theorem or proof obligation to `Tools.Semantics.registry`.
Its controls check dependency ordering, bootstrap isolation, failure handling and deterministic generated bytes.
A narrow build checks each executable and changed tool module.
A temporary constructor probe checks that the producer runs before a stale fold consumer.

Allowed files are generator tools, their shared dispatch, `scripts/generate.py`, reached build rules and documentation.
Generated outputs may change only through the affected producer.
The receipt records exact commands, outputs and any remaining generation limit.
