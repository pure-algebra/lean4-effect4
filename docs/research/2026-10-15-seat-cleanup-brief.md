## The slices, in order

### S1. F3: the algebras' family parameter

- **Rule** (state note §6.9): a type parameter of type `I → Type`, with `I` a finite inductive whose
  constructors take no argument, becomes one OCaml type parameter per constructor of `I`. An
  instance reads each by reducing `R c`. It is exact and needs no cast.
- **Where:** `OCaml5.Lcnf.Types` (`typeParameterIndices`, `kernelTy`, `generate`) and the
  translator's annotations (`OCaml5.Lcnf.Translate`).
- **Consumer:** the host run's closure. `Test.Dogfood.Scenario.Todo.Host.serveBuilt` reaches
  `EffAlgebra` through `superAlg` (`src/Effect4/Api/Supervision.lean`) and `EffAlgebra.id`
  (`src/Effect4/Api/TestClock.lean`).
- **Done when:** `python3 scripts/generate.py --only lcnf` moves no committed byte, or each moved
  byte reads as the rule's; a probe recipe that lowers `serveBuilt` reports no F3 refusal.

### S2. The clock boundary (row 394 (1))

- **Rule:** a reactor's answer is host ingress. It passes the check that a host answer on the tape
  passes: EN8 (`ocaml/engine/e4_engine.mli`), the numeric profile through `E4_clock`.
- **The analysis:** in `OCaml5.Lcnf.ClockFlow`, the result of a call of a parameter whose type is
  `Effect4.Run.Reactor σ` (`src/Effect4/Run/Basic.lean`, called in `Run.driveFrom`) is checked
  ingress, not unknown higher-order production.
- **The check:** one OCaml function in the engine library that walks an answer's naturals through
  `E4_clock`'s profile check, the way `E4_engine.compile` walks a program's literals. A driver
  applies it to every reactor answer before the machine reads it. Its refusal is DI-56's
  distinguished profile refusal, never a defect.
- **Red control:** a reactor that answers an unrepresentable natural is refused by the check.
- **Done when:** the probe recipe lowers `serveBuilt` and `serveBuiltForgetful` with no clock
  refusal; `ClockDiff` (or the generated bytes of the existing roots) shows no change on the
  current roots.
- If the rule needs a design choice past these lines, stop this slice. Write the options in the
  receipt, with a recommendation, and go on to S3.
