## What the slice taught: design flaws and direction (for the Mac seat)

Each item is a reading of this slice's work, with the place that shows it.

1. **One constructor carries two meanings.** `Ty.handle n` is a host handle, or a declared
   name when the table declares `n`. Normalization also spells a reference with no argument,
   `Ty.app n []`, as `Ty.handle n` (`recursive-types-normalize`). So a reader with no table
   cannot tell a name from a handle. The machine mints a host handle for a natural at such a
   column (`externalValue`). So W4b must refuse `Id = number` as a row's answer. A reference form that normalization keeps (`Ty.app n []`, or a new `Ty.ref n`)
   would remove the refusal and the machine's need for a table. Decide it before W4b.
2. **The API is indexed by a row table, not by `SigApp`.** `Built`, `Session program table`,
   `Api.Typed table` and `HostSession.instanceAt` fix `SigApp.ofTable table`. So every datum of
   an application beside its rows needs a twin: `build` and `buildIn`, `admitProgram` and
   `admitProgramIn`, `Built` and `BuiltIn`. Index the API by `SigApp` once, in W4b, then delete
   the twins. Each further twin is debt.
3. **The typed state takes no table.** `Fits` reads no declaration table. So the laws that
   invert the typer against it take `sig.types = []`, about fifteen of them. A program built by
   `buildIn` has the checker's admission, and none of M5 to M7's guarantees. `FitsIn` (W6) is
   the repair, and verified software needs it.
4. **The library roots do not reach the harness.** `lake build Effect4 Effect4.Laws` builds no
   file under `harness/` or `tools/`. So a new structure field broke the keyed emitter at the
   gate, after a commit whose builds passed (`97acd72dd`). A build target over those files
   would catch it at the narrow build.
5. **A gate hid its own error.** `scripts/check-host-protocol.py` sends Lean's output to its
   fixture file, and Lean writes an elaboration error to its output. So the gate failed with
   no message. It should print the captured output on a failure.
6. **The generators assume one platform.** `scripts/generate.py` calls GNU `timeout`, which is
   another program on Windows, and the LCNF recipe passed the 4096 MB cap in one process. The
   second is repaired (`6a5f7787b`).

No other library changes in this slice. W5's declaration block needs a type-alias `Decl` in
lean4-typescript, which is pinned in `lakefile.toml`.

## Proposed decisions rows (proposals only)

1. **A declared name, read iso-recursively** (representation): unfold at elimination, fold at a
   written field type, `Ty.sub` unchanged.
2. **The table in the typing signature, beside by `rfl`** (representation): `Signature.types`,
   filled by `SigApp.signatureIn`; each reader matches on the table first.
3. **The typed state at the empty table** (domain): the laws that invert the typer against `Fits`
   take `sig.types = []` until `FitsIn` lands.
4. **The LCNF generator makes one artifact per process** (method): the recipe in one process
   passes the cap on the PC.
5. **The build under named types stands beside the build** (representation): `Author.buildIn`
   into `BuiltIn`, and `Author.build` reads no table. The callers move when the session reads
   the table.
6. **No row column at a declared name that admits a natural** (domain, for W4b). The machine
   reads no table, and it mints a host handle for a natural at a column `handle n`. So the
   signature's admission refuses such a column, located at the row. `Id = number` as a row's
   answer is refused; a record or a tagged union is not.
