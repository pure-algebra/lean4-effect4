ReadRefusalread

constructorfieldsmeaning
ReadRefusal.unknownHeadnameA call whose head is a reserved name with no Eff reading in that position (Cause.fail outside a cause, Effect.whileLoop outside its suspend).
ReadRefusal.unknownIdentnameAn identifier that is no binder, no reserved name, and no value row.
ReadRefusal.arityheadA row called with an argument list its row table does not print.
ReadRefusal.binderexpectedA lambda, const or step parameter that is not the binder due at that position.
ReadRefusal.shapewhatAny other form the printer never emits; what names the position.
ReadRefusal.negativevalueA negative integer literal.
ReadRefusal.unsupportedStmt—A statement form the printer never emits.
ReadRefusal.annotationsiteA binder, return or local annotation the raw printer never emits; site names the position. This is not arity (an argument list the row table does not print) and not unsupportedStmt (a statement form with no reading): a consumer routing on the alphabet must be able to tell "annotated, not admitted here" from "wrong shape".

PrintRefusalprint

constructorfieldsmeaning
PrintRefusal.internalActionname—
PrintRefusal.layerReftarget—
PrintRefusal.unsafeNamespellingA row table carries an unsafe spelling (colliding with binders or reserved heads).
PrintRefusal.typeSpellingtextA legacy target type has no structural reading in the supported profile. Named by a row's spelling, it is also the refusal of an operation's type arguments (printCall): one of them has no printed form, or the row's call cannot carry them on its head (withHeadTypes).
PrintRefusal.payloadClasstag whyAn error payload class the module cannot declare, named by its tag (decisions row 120).
PrintRefusal.binderTermspellingAn operation that carries a binder term on a row whose printed form is no call, named by the row's spelling: a value row has no argument list to carry the term's function (withFunction). No native row is such a row: the eight term rows are call rows, and each prints its term (the state plan's T5).
PrintRefusal.callbackRequirementpathAn invocation whose programs need a service that the printed parameter's type cannot carry, at the invocation's path (decisions row 340; Codex's HO3-REQ-01): the header closes a parameter's requirement row as never, so tsgo refuses the call. Kept until the target can bind a requirement variable on the header.
PrintRefusal.invocationdefinitionAn invocation with programs of a definition that the signature lacks, or that takes no program, by the definition's position in its block (printInvoke): the row call invokes a definition that takes no program.
PrintRefusal.emptyBlock—A definition block that holds no definition: it would print as its main program alone, and read back as it (printModuleWith).
PrintRefusal.bodiespositionA definition block whose declarations and bodies differ in number, from the definition at this position on (printDefsWith). The checker refuses such a block too.
PrintRefusal.serviceNamenameA name that two definitions of a block with a service share, or that two of the names its services declare share, a key and a layer among them (serviceFault).
PrintRefusal.strayMethoddefinition serviceA definition that is a method of a service the block does not declare, by the definition and the service it names (serviceFault).
PrintRefusal.servicenameA service that does not print, by its name: its initial program is missing, takes a request or a program; it has no method, two with one name, or one whose name is no plain key; or its name or its layer's is a definition's or carries a layer path (serviceFaultOf).
PrintRefusal.serviceMethodservice methodA method of a service that does not print, by the service and the method: its definition is missing, or its request is not the service's state and the method's arguments (serviceFaultOf).
PrintRefusal.declarationsservices typesAn application that declares services or named types, by how many of each, refused at the root by the certified faces (Api.targetSupport). They print at the rows' signature alone, which types a declared service code at its built-in carrier, so the printed types could differ from the certificate's silently. Conservative: an unused declaration is refused too. Kept until emission checks at the application's whole typing signature (R1).

ClassRefusalclass

constructorfieldsmeaning
ClassRefusal.notIdentifier—The tag is not a TypeScript identifier, so no class can be named by it.
ClassRefusal.collides—The tag collides with a name the module already binds: an import (Data, Effect, …), an atom or row of its prelude, a reserved head, a builtin, or one of its own declarations.
ClassRefusal.fieldsDiffer—Two payload types under one tag with different fields: one class cannot declare both.
ClassRefusal.construction—A construction of the payload type outside the class form (Classes.classTag?): _tag is not its first field, its first name and the tag's literal, or a name repeats _tag.
ClassRefusal.unreadable—The class's printed declaration does not read back to its fields (ClassTable.checkedDecl): a field type TypeScript spells like another (number), or a field naming another class.
