# Effect4 counterexample register

Every row here has a witness on `main`: a battery file under `Test/` that a
change to the attacked statement makes red. Rows whose witness lives only in
history (an archived branch, a moved repository, a retired battery) are in
[`Archive/REGISTER.md`](Archive/REGISTER.md) with the same IDs; that file is the
history and this one is the live register. The split was made on 2026-09-13,
by whether the witness path exists in this tree: 138 rows here, 260 there then.
At `dceae006` (2026-10-01) there were 146 rows here and 281 there; the formal
pass's seven rows (last section) make 153 here. Count with
``grep -c '^| `E4-' Test/Counterexamples/REGISTER.md`` (and the same over the archive).

Stable IDs in this file are never reused. A row closes only when its witness
is retained and the repaired declaration or theorem mechanically rejects the
attack. `PINNED` means the witness already exists at the named immutable source
revision; `SEEDED` means the packet has frozen the attack but no immutable
provenance pin for its Effect4 witness has yet been recorded. `RESERVED` means
the stable row and forced repair are frozen now, while the executable witness
belongs to a later packet whose declarations are not open yet. `MOVED` means
the row and its witness now live in another repository at a named tag; the
ID is retained here so citations resolve, and the row is not reused.
`REPAIRED` (with its date) means the forced repair has landed: the repaired
declaration or theorem rejects the attack, and the witness is kept as a
regression beside it; a qualifier says when the repair covers part of the
statement only ("for host answers only"), and an earlier status may follow
after a semicolon. `RETIRED` (with its date and reason) means the attacked
statement no longer exists in the tree — the declaration it named was cut or
replaced — so the row closes without a repair; it stays, unreused.

Four IDs were minted twice, once in each file, for different attacked
statements: `E4-TYPED-CE-003`, `E4-SCHED-CE-004`, `E4-PROV-CE-005` and
`E4-PROV-CE-006` name one row here and another in the archive. Neither is
renumbered, so every existing citation still resolves; a citation that needs
the distinction names the file it means.
